# AI 数智化进阶班封面执行指南

交付 **1080 × 1920、9:16 的竖屏 1080P PNG**。画面从上到下是固定双讲师、金色标题和本次配图。制作前查看[标准参考图](../assets/reference.png)，以用户本次明确指定的例外为准。

## 1. 确认本次素材和改动范围

- 取本次标题原文和清晰度最高的原始配图。标出必须保留的人数、站位、手势、服饰、胸牌和证书，并检查原照是否拍全腿脚。
- 用户只说换配图时，沿用当前已确认的标题、排版和[双讲师蓝紫底图](../assets/base.png)，替换下方合照。按新照片的自然比例重排下方位置，继续检查占幅、全身和清晰度。
- 红框表示配图的目标占幅，其边线仅用于工作参考。标题文字取自用户请求，清理配图背景时一并去掉会场屏幕文字和印刷人像。

## 2. 抠图并取得完整全身素材

| 素材情况 | 执行方式 |
| --- | --- |
| 原照从头到鞋完整 | 抠图时保留每个人的头发、双腿、鞋子和衣摆，也保留原有站位、手势和关键物件。 |
| 原照在下方截断，用户要求全身 | 优先使用同一张合照的完整原图或完整版本。只有截断版本可用时，可在原照下缘局部扩图，补齐缺失的小腿、裤脚、裙摆和鞋。用户要求完全使用实拍时，缺脚素材需要完整原图才能满足全身要求。 |
| 用户指定半身构图或保留会场场景 | 按指定构图处理。保留会场且需要完整人物时优先用 `contain`，在裁切仍能容纳所有需保留内容时可用 `cover`。 |

- 使用同一张照片的合格透明 PNG，或用 imagegen 取得透明抠图。对比原照检查人数、身份、边缘和物件。生成的抠图改动五官、姿势、服饰或胸牌时，改用贴合原照的遮罩合成，保留原照人物像素。
- 局部扩图时把原照人脸、上身和已拍到的腿部保留为原图层，补画集中在缺失下缘。检查裤脚长度、鞋尖和鞋底、裙摆轮廓及阴影接缝。采用补画时在交付说明指出补画的部位，鞋款等缺失细节属于推定。
- 在深蓝或成图底色上检查发丝、肩线、手势、人和人之间的空隙以及鞋边。清理残留的屏幕光边、文字、家具和地毯。合成素材使用带透明通道的 PNG。

## 3. 调整占幅和标题，为全身留足空间

1. 按透明主体的实际边界等比缩放整组，让横向合照接近红框或配图区两侧。渲染器在空间允许时以画布宽约 96% 为放大目标，实际大小取决于合照比例和可用高度。
2. 人物显小、四周还有空间时，优先放大整组和调整上下布局。副标题放得下、手机上也能读清时，可合为一行，给全身照增加纵向空间。需要分两行时按语义断句，统一字号、字重、字距和行距。
3. **全身完整优先于铺满配图区。** 空间冲突时调整标题断句、间距和配图位置，必要时接受少量侧边留白。成图中每个人从头发到鞋底完整可见，保留原始比例和相对站位。
4. 主标题保留原字、标点和用户指定的换行，采用亮金渐变。中文用 01 号「字魂武林江湖体」，ASCII 字母用 Arial 粗斜体。副标题用金色 Noto Sans SC 黑体。字号和间距直接在渲染器中调整，保持首行的视觉优先级和手机阅读清晰度。

## 4. 逐脸检查清晰度、亮度和质感

| 成图原尺寸下看到的问题 | 执行方式 |
| --- | --- |
| 新原图已清楚，人脸亮度合适 | 优先保留原照五官和皮肤细节，用高质量缩放完成合成。 |
| 放大后眼眉、嘴唇或眼镜轮廓偏糊 | 逐脸局部清晰化，先试适度锐化或超分，明显模糊时可进行局部人脸修复。修复层与原照对齐后轻柔融合，检查眼镜边缘和下巴接缝。 |
| 人脸偏暗、发灰或与讲师图质感差异明显 | 以上方讲师照的亮度、暖色高光和柔和阴影为参考，逐脸提亮阴影、自然美白和轻磨皮，保留肤色层次和皮肤纹理。 |
| 修复后五官、神态、眼镜或发型出现偏差 | 对照原照降低修复强度，在偏差部位恢复原照像素，再做局部调色和细节处理。 |

## 5. 渲染、验收和交付

按[技能入口](../SKILL.md)的命令，用[渲染器](../scripts/render_cover.py)合成。以 UTF-8 JSON 传入绝对配图路径、换行后的 `title` 和相应的 `fit`。透明合照用 `cutout`。检查讲师、字组和合照之间的空白、光带衔接与上下视觉重心。标准参考图的上下计算留白各约 151 px，可用作平衡参考。

- [ ] **手机预览**　标题看得清，整组合照靠近配图区两侧且大小合适，正文与人物之间留有间距。
- [ ] **原尺寸预览**　逐字核对标题。逐人核对人数、站位、面孔、手势、胸牌或证书、双腿和鞋。重点看眼眉与眼镜细节、脸部光影和抠图或补画接缝。
- [ ] **文件检查**　实际打开 1080 × 1920 的 PNG。分别检查像素尺寸和放大后的原照细节，按上述两种视图都验收后交付。
- [ ] **交付**　发送最终封面的预览和下载链接。有局部扩图时说明具体部位。用户只要求换配图时，核对标题和上方讲师与上一版一致。
