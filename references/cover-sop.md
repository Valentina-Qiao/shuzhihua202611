# AI 数智化进阶版封面制作 SOP

**交付标准**　1080 × 1920 竖版 PNG。以已确认的「AI赋能」武林江湖体版为准，Skill 包内的标准参考图位于 `assets/reference.png`。画面从上到下是双讲师、金色标题、下方配图。蓝紫霓虹底图和讲师由模板提供。

## 1. 核对本次素材

取得标题原文和下方配图，标记要保留的人物、证书或产品。用户给出题眼、换行、裁切框或要保留的场景时，按本次要求排版。照片上的屏幕文字、海报人物等属于参考素材，不作为新增文案。

## 2. 断句和字体

- **首行**放题眼。中文用 01 号「字魂武林江湖体」，ASCII 字母用 Arial 粗斜体，使用亮金渐变。参考中的「AI」和「赋能」都比下两行字大。
- **下两行**用金色 Noto Sans SC 黑体，字号、字重、字距一致。较长的副标题按语义拆成两行，保留完整词组和原字。例如「AI赋能／解锁轻松高效的／营销新方式」。短标题可用一至两行。
- **标题区**是上方讲师与下方配图之间的空白。居中并尽量用足高度，保持均衡行距和可读笔画。参考输出的字面大约位于画面 `y=650–1040`，标注红框仅用于确定范围。若边缘碰到人物或光效压过文字，先调整断句或字号并重新排版。

## 3. 下方配图

1. 多人合照优先去背景。使用已有的真实透明 PNG，或用 imagegen 做透明背景抠图，保留全部真实人物、原有次序、服饰、手势以及要留的证书。去掉会场屏幕、屏幕里的印刷人物、文字、地毯和家具。把抠图贴在深蓝背景上查看发丝、肩线、人与人之间的空隙及证书小字。若外貌、数量或关键物件明显变化，换用更忠实的抠图后再合成。
2. 多人组照按透明主体的实际边界等比放大，可铺到画面两侧。确保最靠边的人清楚可见，脚部或自然淡出的位置不越过参考图下方的留白区。参考中主体从约 `y=1075` 开始，末端约 `y=1585`。单人或窄图按可用高度等比放置。
3. 用户需要保留场景时，宽图用 `contain` 优先保住两边的人或物件；画面充裕时用 `cover`，必要时调整 `crop` 和 `focus`。有可用透明蒙版时用 `cutout` 合成。

## 4. 合成、验收和交付

在模板内用 `scripts/render_cover.py` 按 UTF-8 JSON 渲染。请求含 `title` 和 `photo`，视图片选用 `fit`。文件用绝对路径，标题按选定断句用 `\n` 换行。合成后把讲师、标题、下方主体及围绕内容的光带视为同一个内容组，比较最高点和最低点，让上下背景留白大致相当。延伸到画布边缘的光点和线条属于背景。参考成图的计算留白是上下各 151 px。

请求和运行命令如下。将路径替换成实际文件，Python 需要 Pillow 和 NumPy。

```json
{
  "title": "AI赋能\n解锁轻松高效的\n营销新方式",
  "photo": "F:/photos/group-cutout.png",
  "fit": "cutout"
}
```

```powershell
& $pythonPath "$skillDir/scripts/render_cover.py" --request "$requestPath" --output "$outputPath"
```

若找不到已安装的武林江湖体，可用 `--brush-font` 传入同款字体的实际路径。外部字体文件随系统安装获取。

导出前逐项检查

- 逐字核对标题和断句。首行有视觉优先级，后两行排版一致。缩小看时整组清楚，画面上只呈现成品。
- 核对人物数量、面部、边缘与关键物件，确认多人合照铺开后两侧和底部依然完整。
- 核对成图是 1080 × 1920 PNG，能正常打开。发送最终预览和下载链接。用户要求比较字体或颜色时单独做试样，正式模板以用户确认的最终款为准。

## 常见问题与处理

| 问题 | 处理 |
| --- | --- |
| 长副标题横向挤满，字只能缩得很小 | 先按词组拆成两行，保持原文和句意，再配同字号、等行距。 |
| 三行标题没有用足中间区域，或超出了参考框 | 对照配图之间的空白，调整原生字号与行距，使标题居中铺开，留出人物与文字之间的间隔。 |
| 字看起来粗、糊，或三行字距忽大忽小 | 用字库重新渲染，选合适字重和统一字距。检查画面缩小时的笔画，不放大整张标题位图或加厚描边。 |
| 艺术字换上后首行反而显小 | 对比可见字高和整组视觉重心。首行用亮金武林江湖体搭配粗斜体 AI，后两行用更小、醒目的金色黑体。 |
| 下方合照看起来像贴了一块会场照片，或人物过小 | 清理环境背景和印刷人物，按透明主体的实际宽度等比放大，允许横向铺满。 |
| 抠图漏人、误留背景或改了证书 | 与原照对照人数、顺序和重要物件，检查通透区域，修好抠图再排版。 |
| 上下空白失衡或合照压到下方装饰 | 按内容组边界垂直居中，限制下方主体的最低点，必要时等比缩小。 |
